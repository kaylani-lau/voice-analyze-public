# Voice Map

Live voice map for voice practice: brightness left to right, weight bottom to top, trained on your
own labeled takes. Tap a corner, do that voice, and the map learns from it.

Everything runs in the browser. Takes, the trained map and profiles are saved in the browser on that
device and never uploaded. **Export** and **Import** move them between devices. It keeps your newest
50 takes.

Try it on a computer: `python3 -m http.server 8766` in this folder, then open http://localhost:8766/.

On a phone, open it from an `https://` address (browsers only allow the mic on secure pages), then use
the browser menu → **Add to Home screen**.
